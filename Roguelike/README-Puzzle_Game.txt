But du jeu :
- Chaque niveau a 3 étoiles à atteindre avec un score minimal.
- Pour augmenter votre score vous devez placer des tetrominos sur la grille.
- Si vous vous êtes trompés, vous pouvez reprendre un tetromino déjà placé mais attention, cela remet le multiplicateur à 1.
- Dans le menu vous pouvez baisser le son des bruitages et de la musique.

- Niveau 1 : 3 tetrominos disponibles
- Niveau 2 : 2 tetrominos disponibles
- Niveau 3 : 2 tetrominos disponibles et rotations bloquées.

Contrôles :
CLic gauche :
- Appuyer sur les boutons
- Sélectionner les tetrominos

Clic droit :
- Désélectionner les tetrominos

Q :
- Faire tourner le tetromino sélectionné dans le sens antihoraire

D :
- Faire tourner le tetromino sélectionné dans le sens horaire
